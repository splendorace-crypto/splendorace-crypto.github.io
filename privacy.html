Privacy Policy — eBay Listing Agent

Last updated: 27 October 2026 · Contact: splendor.ace@gmail.com

eBay Listing Agent ("the app") is a private tool. Its owner uses it on the owner's own Windows PC for the owner's own eBay selling work. Only the owner signs in, with the owner's own Google account. This policy explains what the app does with data from Google APIs.

1. Google user data the app accesses

The app uses only the Google Sheets API. It opens only the owner's listing spreadsheet, which is named in the app's settings. A run stops if the spreadsheet's name is different.

Read (scope spreadsheets.readonly)

  • The rows of the listing sheet, columns A to AO: row number, product title, reference eBay listing URL, supplier page URL, prices, category, points, notes, assignee, listing date, SKU, profit and shipping policy.
  • The header row and the cell that holds the description template.
  • The background colour of cells, and the sheet's conditional format rules. These show which rows are marked (for example, unprofitable rows).
  • The spreadsheet's title. It is used only to confirm the right spreadsheet is open.

Write (scope spreadsheets)

  • Only these result columns of the listing rows: AA (assignee name), AB (listing date), AD (SKU input), AM (note), AT (do-not-retry checkbox), AR (eBay Item ID) and AS (listing status).
  • The app reads each value back to confirm it. It never writes formulas, never changes other columns and never deletes rows.

The app does not access Google Drive files, Gmail, Contacts, Calendar or any other Google data.

2. How the data is used

The data is used only to perform the owner's listing work:

  • choosing rows to list
  • checking the supplier's stock and price
  • preparing and publishing the eBay listing on the owner's eBay account
  • recording the result in the same spreadsheet

The app does not use Google user data for advertising, does not sell it, and does not use it to train AI models.

3. Where the data is stored

  • Only on the owner's PC. There is no server, no cloud database and no analytics.
  • The Google sign-in tokens are stored in a local folder on that PC. They are never written to logs.
  • Working records are stored on the same PC: a local database used to prevent duplicate listings, run logs (deleted after 90 days) and listing drafts.

4. Data sent to other services

To do the owner's listing work, parts of the listing data are sent to these services. Nothing else is shared with any other party.

ServiceWhat is sentWhy
eBay (eBay APIs, the owner's seller account)Listing title, price, SKU, description, photos, item specifics, and the ID of the reference eBay listingTo create the listing and check it
Anthropic (Claude API)Product title, notes and the text and photos of the supplier's product pageTo check the listing contents and write the English text. Under Anthropic's commercial terms, API data is not used to train its models.
EPC (ezperfectcontrol.link, the owner's SKU tool)The supplier page URLTo create the SKU
Supplier websitesA visit to the supplier page URL (a normal page view)To check stock and price
Google Translate (public web endpoint)Short product or character namesTo find their English names

5. Compliance with Google's policy

The app's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

6. Removing access and data

The owner can remove the app's access at any time at myaccount.google.com/permissions. To remove the stored data, delete the app's local folders on the PC: the sign-in tokens, the database and the logs.

日本語

eBay Listing Agent は、所有者が自分の Windows PC で、自分の eBay 出品業務のために使う非公開のツールです。サインインするのは所有者本人の Google アカウントだけです。

  • 使う Google API： Google Sheets API だけです。開くのは、設定で指定した所有者の出品シート1つだけです。
    • 読み取り：出品行の A〜AO 列、見出し行、説明文テンプレート、セルの背景色、条件付き書式、スプレッドシート名
    • 書き込み：AA（出品者）、AB（出品日）、AD（SKU入力）、AM（備考）、AT（再処理対象外）、AR（eBay Item ID）、AS（ステータス）の列だけ。数式や他の列は変更しません
  • 利用目的： 出品する行の選定、仕入元の在庫・価格の確認、所有者の eBay アカウントへの出品、結果のシートへの記録だけです。広告、販売、AI の学習には使いません。
  • 保存先： 所有者の PC の中だけです。サーバーは使いません。認証トークンは PC 内のフォルダに保存し、ログには出しません。ログは90日で削除します。
  • 外部への送信： 出品業務に必要な範囲で、次のサービスに送ります。それ以外の第三者には提供しません。
    • eBay：出品内容
    • Anthropic（Claude API）：商品名・備考・仕入元ページの文面と写真。内容の確認と英文作成のため。学習には使われません
    • EPC：仕入元 URL。SKU 発行のため
    • 仕入元サイト：商品ページの閲覧
    • Google 翻訳：短い商品名・キャラクター名
  • アクセスの取り消し： myaccount.google.com/permissions からいつでも取り消せます。
