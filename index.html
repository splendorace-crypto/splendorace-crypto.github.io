eBay Listing Agent

A private tool for the owner's own eBay selling work. It is not a public service and is not offered to other users.

What it does

eBay Listing Agent runs on the owner's own Windows PC. It helps the owner list products on the owner's own eBay seller account:

  • It reads product rows from the owner's own listing spreadsheet in Google Sheets: product title, reference eBay listing, supplier page URL, prices and notes.
  • It checks stock and price on the supplier's public product page, then prepares the eBay title, description, photos and item specifics.
  • It publishes the listing to the owner's eBay account through the eBay API.
  • It writes the result back to the same spreadsheet: assignee name, listing date, SKU, eBay Item ID, status and notes.

Why it uses Google Sheets

The listing work is managed in one Google Sheets spreadsheet that the owner and the owner's staff share. The app uses the Google Sheets API to read the rows to list and to record the results. It opens only that one spreadsheet. A run stops if the spreadsheet's name is not the expected one.

  • https://www.googleapis.com/auth/spreadsheets.readonly — to read the listing rows. This is used for checks that must never write.
  • https://www.googleapis.com/auth/spreadsheets — to write the result columns of the listing rows. The app never changes formulas or other columns.

The app does not use Google Drive, Gmail, Calendar or any other Google user data.

Who can use it

Only the owner signs in, with the owner's own Google account. The app has no public sign-up, no website login and no server. Everything runs on the owner's PC.
